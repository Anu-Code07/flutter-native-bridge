# nativeflow_bridge_macos

macOS runtime shell for generated NativeFlow Bridge Flutter plugins.

This package provides the Swift plugin entrypoint and runtime primitives used
by generated macOS bridge integrations.

## Usage

Add the package to a Flutter plugin or app that consumes generated NativeFlow
Bridge macOS code:

```yaml
dependencies:
  nativeflow_bridge_macos: ^0.1.0
```
