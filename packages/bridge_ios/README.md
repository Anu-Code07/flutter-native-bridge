# nativeflow_bridge_ios

iOS runtime shell for generated NativeFlow Bridge Flutter plugins.

This package provides the Swift plugin entrypoint and runtime primitives used
by generated iOS bridge integrations.

## Usage

Add the package to a Flutter plugin or app that consumes generated NativeFlow
Bridge iOS code:

```yaml
dependencies:
  nativeflow_bridge_ios: ^0.1.0
```
