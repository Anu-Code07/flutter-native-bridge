# nativeflow_bridge_linux

Linux runtime shell for generated NativeFlow Bridge Flutter plugins.

This package provides the C++ plugin entrypoint and runtime shell used by
generated Linux bridge integrations.

## Usage

Add the package to a Flutter plugin or app that consumes generated NativeFlow
Bridge Linux code:

```yaml
dependencies:
  nativeflow_bridge_linux: ^0.1.0
```
