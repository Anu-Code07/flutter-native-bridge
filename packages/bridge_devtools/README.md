# nativeflow_bridge_devtools

Flutter DevTools integration foundation for inspecting NativeFlow Bridge
traffic and timelines.

This package contains the DevTools extension metadata and telemetry primitives
used to inspect generated bridge calls during development.

## Usage

```yaml
dependencies:
  nativeflow_bridge_devtools: ^0.1.0
```

Use the exported timeline primitives from generated bridge diagnostics or
custom tooling integrations.
