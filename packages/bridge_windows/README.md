# nativeflow_bridge_windows

Windows runtime shell for generated NativeFlow Bridge Flutter plugins.

This package provides the C++ plugin entrypoint and runtime shell used by
generated Windows bridge integrations.

## Usage

Add the package to a Flutter plugin or app that consumes generated NativeFlow
Bridge Windows code:

```yaml
dependencies:
  nativeflow_bridge_windows: ^0.1.0
```
