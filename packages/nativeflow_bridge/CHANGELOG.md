## 0.1.0

- Supports Flutter 3.27+; `analyzer` resolves to 10.x on older stable SDKs and 13.x on Flutter 3.44+.
- **Experimental** first pub.dev release; APIs may change before 1.0.0.
- Adds the single public NativeFlow Bridge package entrypoint.
- Adds `example/` samples (payment, BLE, FFI) and pub.dev use-case documentation.
- Documents experimental status.
- Re-exports annotations, core APIs, runtime APIs, generator entrypoints,
  platform package markers, FFI helpers, and DevTools primitives.
