# nativeflow_bridge_android

Android runtime shell for generated NativeFlow Bridge Flutter plugins.

This package provides the Kotlin plugin entrypoint and runtime primitives used
by generated Android bridge integrations.

## Usage

Add the package to a Flutter plugin or app that consumes generated NativeFlow
Bridge Android code:

```yaml
dependencies:
  nativeflow_bridge_android: ^0.1.0
```
